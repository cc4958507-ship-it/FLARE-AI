# Craftwork skills used

The uploaded ZIP is a collection of optional methods, not a requirement to combine every design style or execute embedded setup commands. Relevant skills were applied within the user's request and the FLARE product specification.

- interface-design: task-first research workbench; domain exploration, hierarchy, tokens, native controls and a repeated observation-window motif.
- antislop + antislop-ui: during-build mode explicitly selected by the user; no fabricated evidence, invented metrics, decorative status lights or dead controls. The text wordmark and initial are placeholders for a future formal identity.
- better-accessibility: keyboard navigation, native dialogs, unique accessible names, route focus, form labels, all-sample table, live state announcement and reduced motion.
- design-a-chart: observed channel changes over virtual time, fixed [0,1] scale, sim_unit labels, null gaps and a full table alternative. ECharts is retained from the product specification rather than changing to the skill's example chart library.
- accessibility-lead: independent source review identified three issues and rechecked their fixes. Its separately named specialist packages and a11y-core renderer are not included in this ZIP, so the provided better-accessibility skill was used for the independent review. This is not claimed as a full specialist-team or assistive-technology certification.

No AGENTS.md pointer block or global preference was installed. Selected guidance was used for this build; the original ZIP remains unchanged under attachments.
